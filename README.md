# design-tdah

Une skill Claude Code pour concevoir des pages, des apps et des tableaux de bord
qu'un cerveau TDAH peut vraiment utiliser : une action par écran, le temps rendu
concret, tout visible, le droit à l'erreur, et des victoires qui restent.

Les cinq principes viennent d'[adhd-design-expert](https://github.com/curiositech/some_claude_skills)
(MIT), relus et traduits en français. Le style « feuille sur table » vient de
[Mike IA](https://mikeia.com), l'IA pour les entrepreneurs TDAH.

## Installer

Avec l'outil `skills` :

```bash
npx -y skills add Mikebuildsia/design-tdah --skill design-tdah -g -a claude-code -y
```

Ou sans rien installer : télécharger `skills/design-tdah/SKILL.md` et le poser dans
`~/.claude/skills/design-tdah/SKILL.md`, puis redémarrer Claude Code.

## Utiliser

```
/design-tdah
Refais l'écran d'accueil de mon app pour un cerveau TDAH.
```
